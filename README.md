# 🎵 zsepyDownloader

**zsepyDownloader** is a modern Windows desktop application with an **embedded YouTube browser**, 1-click MP3 downloader, and built-in music player.

Created by **zsepyDevGroup**  
GitHub: [https://github.com/Janos405](https://github.com/Janos405)

---

## 🚀 How to Run

Choose whichever version suits you best:

1. **Windows Installer (Recommended):**
   - Installs the app to your system, creates a Desktop shortcut and Start Menu entry.

2. **Portable Single Executable:**
   - Standalone single executable, runs immediately with no installation required.


## 🛡️ Built-in Dependency Engine

- Both `yt-dlp` and `ffmpeg` are **pre-bundled directly** inside the app.
- If run on any fresh Windows computer without dependencies, the app will **automatically download and configure them in the background** with zero manual setup.

---

## ✨ Features

- **Embedded YouTube Experience:** Browse YouTube, log into your channel, and access **My Videos / Studio** directly inside the app.
- **1-Click Floating Download Dock:** Automatically detects when you are watching a video and shows an instant **Download MP3** button.
- **Quality Presets:** 320 kbps (Studio Quality), 256 kbps, 192 kbps (Recommended), 128 kbps.
- **Integrated Audio Player:** Listen to your downloaded MP3s directly inside the app with volume and seek controls.
- **Batch Downloader:** Paste dozens of links to queue them all up simultaneously.
- **File Explorer Integration:** One click to highlight the downloaded MP3 in Windows Explorer.
